# 🚀 SkillSync - Freelancing Platform

A modern freelancing platform where clients can post projects and skilled freelancers connect seamlessly.

🌐 **Live Demo:** https://skillsync.pythonanywhere.com/  
💻 **GitHub:** https://github.com/Ardra-KP/SkillSync

---

### ✨ Features
- 🔐 Role-based Authentication (Client / Freelancer)
- 📝 Post, Edit & Manage Projects
- 👤 Dynamic Profiles & Dashboard
- 🎨 Modern, Responsive UI with Tailwind CSS
- 🔒 Secure Django Authentication System

### 🛠️ Tech Stack
- **Backend:** Python, Django
- **Frontend:** HTML, CSS, Tailwind CSS, JavaScript
- **Database:** SQLite (Development)
- **Deployment:** PythonAnywhere

### ⚙️ Quick Start

```bash
# Clone the repo
git clone https://github.com/Ardra-KP/SkillSync.git
cd SkillSync

# Install dependencies
pip install -r requirements.txt

# Run migrations
python manage.py migrate

# Start server
python manage.py runserver
